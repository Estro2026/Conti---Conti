# UI & Art Direction Skill

## Scopo

Usare questa skill quando bisogna:

- definire una direzione UI;
- trasformare brand e moodboard in interfaccia;
- progettare un design system;
- verificare coerenza visuale;
- migliorare art direction;
- controllare consistenza cross-page.

---

# 1. Principio

Ogni scelta visiva deve derivare da almeno uno di questi elementi:

- brand;
- contenuto;
- target;
- UX;
- funzione;
- materiale cliente;
- direzione approvata.

Evitare decorazioni senza motivazione.

---

# 2. Visual Direction

Definire:

- personalità;
- tono;
- intensità;
- formalità;
- livello di sperimentazione;
- percezione desiderata;
- elementi distintivi;
- elementi da evitare.

---

# 3. Palette

Definire:

- primary;
- secondary;
- accent;
- neutral;
- functional colors;
- background;
- text colors;
- contrast relationships.

Non introdurre nuovi colori arbitrariamente.

---

# 4. Typography

Definire:

- display;
- H1;
- H2;
- H3;
- body;
- label;
- CTA;
- weights;
- line-height;
- tracking;
- max-width.

La gerarchia deve essere evidente anche senza colore.

---

# 5. Grid

Definire:

- container;
- columns;
- gutter;
- max-width;
- alignment;
- offset;
- vertical rhythm.

---

# 6. Spacing System

Usare una scala coerente per:

- section spacing;
- component spacing;
- padding;
- gap;
- text spacing;
- form spacing.

Evitare valori casuali pagina per pagina.

---

# 7. Components

Definire regole comuni per:

- header;
- navigation;
- CTA;
- cards;
- form;
- accordion;
- tabs;
- modal;
- carousel;
- tags;
- footer.

---

# 8. States

Considerare:

- default;
- hover;
- focus;
- active;
- selected;
- disabled;
- loading;
- error;
- success.

---

# 9. Images

Definire:

- photographic direction;
- crop;
- aspect ratio;
- focal point;
- treatment;
- relation with typography;
- use as background or content;
- consistency.

---

# 10. Iconography

Definire:

- stroke / fill;
- weight;
- size;
- corner style;
- optical alignment;
- consistency.

Non mescolare famiglie incompatibili.

---

# 11. Composition

Valutare:

- hierarchy;
- density;
- whitespace;
- rhythm;
- balance;
- asymmetry;
- layering;
- scale.

---

# 12. Differenziazione

Le pagine devono appartenere allo stesso sistema senza sembrare duplicate.

Differenziare quando utile:

- hero;
- composition;
- imagery;
- section rhythm;
- emphasis.

---

# 13. Cross-page consistency

Controllare:

- CTA;
- card;
- radius;
- border;
- typography;
- spacing;
- imagery;
- iconography;
- form;
- states;
- motion.

---

# 14. Anti-generic check

Chiedere:

- questo elemento appartiene davvero al brand?
- potrebbe stare su qualunque altro sito?
- deriva da una reference copiata troppo letteralmente?
- è una scelta progettuale o una decorazione automatica?

Se necessario segnalare:

`GENERIC_VISUAL_PATTERN`

---

# 15. References

Usare reference per:

- principi;
- qualità;
- comportamento;
- proporzioni;
- direzione.

Non replicare direttamente:

- layout;
- identità;
- componenti distintivi;
- effetti proprietari.

---

# 16. Responsive

La UI deve essere definita anche per:

- laptop;
- zoom;
- tablet;
- mobile;
- touch.

Non progettare solo il desktop.

---

# 17. Accessibility

Verificare almeno:

- contrast;
- focus visibility;
- text legibility;
- touch target;
- motion sensitivity;
- color independence.

---

# 18. Motion

La motion direction deve essere coerente con:

- ritmo;
- brand;
- gerarchia;
- funzione.

Non animare tutto.

---

# 19. Quality Check

Prima di considerare la UI coerente verificare:

- [ ] visual direction chiara
- [ ] palette coerente
- [ ] typography system
- [ ] spacing system
- [ ] grid
- [ ] components
- [ ] states
- [ ] images
- [ ] iconography
- [ ] responsive
- [ ] accessibility
- [ ] cross-page consistency
- [ ] generic-style review

---

# 20. Regola finale

Un buon design system deve permettere variazione senza perdere identità.

La coerenza non deve trasformarsi in monotonia e la creatività non deve trasformarsi in incoerenza.
